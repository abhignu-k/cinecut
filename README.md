# cinecut

Context-aware, rhythm- and story-synced AI vertical (`9:16`) cinematic edit engine.

> Status: Early v0.1 MVP under active development.

## Requirements
- Python `3.11–3.13` (tested on `3.12`)
- `ffmpeg` and `ffprobe` on `PATH`

## Development Quickstart

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest
```
